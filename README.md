# Exploradores do Mundo

Jogo educativo de perguntas e respostas sobre o **planeta inteiro**: capitais, bandeiras, continentes, animais, família, futebol, espaço, ciência e história das guerras mundiais (datas e nomes, em nível escolar).

Arquivo principal do jogo: `jogo_mundo_300.html`

---

## Como jogar

1. Abra o arquivo `jogo_mundo_300.html` no navegador (Chrome, Edge, Firefox, Safari).
2. Ou publique o arquivo no **GitHub Pages** e jogue pelo link do site.
3. Leia (ou ouça) a pergunta, digite a resposta e aperte **Verificar**.
4. Se não souber, aperte **Ver resposta** (a pergunta é **anulada** e não vale ponto).
5. Depois de acertar ou ver a resposta, leia a caixa **Saiba mais** para aprender um pouco mais.

### Botões

| Botão | Função |
|--------|--------|
| **Verificar** | Confere a resposta |
| **Ver resposta** | Mostra a resposta e anula a pergunta |
| **Ouvir pergunta** | A voz lê a pergunta de novo |
| **Limpar** | Apaga o que você digitou |
| **Próxima** / **Anterior** | Vai para outra pergunta |
| **Ir** | Pula para um nível escolhido |
| **Recomeçar do zero** | Apaga o progresso salvo neste aparelho |

## Conteúdo do jogo

- **500 níveis**
- **30 perguntas por nível**
- Temas misturados em cada nível:
  - Animais
  - Família
  - Futebol e esportes
  - Espaço e planetas
  - História das guerras mundiais (datas, países, tratados, ONU e Liga das Nações)
  - Geografia
  - Bandeiras (com imagem)
  - Capitais de países de todos os continentes
  - Ciência e natureza

No menu **Tema**, você pode filtrar um assunto ou jogar a **mistura de tudo**.

---

## Recursos

- **Voz em português**: lê a pergunta e diz “Acertou” ou “Errou”
- **Imagens**: bandeiras dos países; planetas e animais com símbolos visuais
- **Saiba mais**: explicação extra após acertar ou ver a resposta
- **Progresso salvo**: o nível, a pergunta e os acertos ficam gravados no navegador
- **Fundo de espaço**: visual com estrelas

### Sobre o progresso salvo

O jogo usa o armazenamento local do navegador (`localStorage`).

- Se você fechar o computador e voltar **no mesmo navegador** e **no mesmo endereço** (mesmo arquivo ou mesmo site do GitHub), continua de onde parou.
- O progresso fica no **aparelho de quem joga**, não no servidor do GitHub.
- Cada pessoa tem o seu próprio progresso.

---

## Como colocar no GitHub

1. Crie um repositório no GitHub.
2. Envie o arquivo `jogo_mundo_300.html` (e este `README.md`, se quiser).
3. Em **Settings → Pages**, publique a branch principal.
4. Abra o link gerado pelo GitHub Pages para jogar online.

Você pode renomear o arquivo HTML para `index.html` se quiser que o site abra direto na página inicial.

---

## Requisitos

- Navegador moderno
- Som ligado (para a voz)
- Internet (para carregar as **bandeiras**). Planetas e animais funcionam mesmo offline.

---

## Observações importantes

- História das guerras mundiais aparece só com **datas, países e nomes de tratados**, de forma escolar.
- O jogo **não** trata de conflitos atuais.
- Algumas perguntas aceitam mais de uma forma de escrita (ex.: `Brasília` ou `Brasilia`).
